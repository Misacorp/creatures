# The arc: how the story comes up, chapter by chapter

Status: **draft, not accepted** (2026-11-18). Spoilers: read `README.md` in this folder first.

The story is told per server. A chapter opens on a server when that server reaches a milestone **together**; no player opens one alone, and no chapter ever closes, expires or can be missed (valley filters F-1, F-7: a newcomer finds every fragment the server has opened, in the places where they lie).

The story needs **no new mechanic**. A chapter is only a set of fragments on surfaces the game already has or already plans (see "Surfaces" in the skill). Milestones below are examples in the valley plan's own terms; the real gates are picked when a chapter is built, and Misa decides them.

"Brings into reach" means enough fragments exist for a server that compares notes to work the fact out. It never means a fragment states it.

## Pace

- A chapter is slow: weeks to months of a server's play. Between milestones the world adds **texture** only (fragments that carry mood and no clue), so a quiet month still has new small things to read.
- A milestone's own moment is one object or one scene, shown where it happened (a lamp-housing under the roots where the Thornmother fell, an older plaque under the new one). The Gazette may carry one plain headline about what was found. It never says what it means.
- Each chapter answers one question from the chapter before and opens a smaller, sharper one. Never answer a question in the chapter that asks it.
