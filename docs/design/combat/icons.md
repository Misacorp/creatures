# Combat v2 icons: the audit

Status: 2026-11-01, **concept art for Misa to review (round 2, after his review the same day)**; nothing here ships. The last item of roadmap phase 3 (`content-as-data.md`, section 8: "one icon per keyword that names a rule a player meets on the board, and per attack shape"). The art is the concept set `combat-icons` (`apps/activity/src/sprites/concepts/combat-icons.ts`, draw it with `pnpm art combat-icons`; the whole set with the shipped glyphs it reuses is the sheet that command writes, `combat-icons.png`).

**The rule used.** Fewer is better (Misa: less to learn). An icon is made only for something a player meets **on the board, as a picture**, that no shipped glyph already says, and whose place is too small for a word. A word that the board already shows by lighting slots, or that only appears inside Knack text, stays text. Colour is never the only cue, so every new icon has a shape of its own (the studio checks each is at least 6 pixels from every shipped glyph).

**Where each icon goes** is fixed by the proposal's "On the board" list (`proposals/001-combat-v2.md`): a boss move's icon sits on every creature it was announced on and on the boss-turn strip; marks, stacks and the Sure Crit count sit as small chips; the Escalating meter and the rule-card icons sit on the boss card; the boss card's move tiles (a tiny arena with the shape lit) need no icon.

Why the three board icons share one grid: Quake, Cross and Checker are the shapes with no shipped picture, and each is literally "which slots are lit". One drawing language (lit blocks on a 3x3 board; Checker is a 4x4 board of 2-pixel squares so it reads as a checkerboard and not as the five on a die) means a player who learns one reads all three. Why One-shot has its own: it is one move (Judgement Bolt), but it is the one hit that ignores Attack, and a player has to be able to see it coming; it is the first icon to cut if Misa wants fewer shape icons (then it shares `reticle` with Strike and the label says One-shot).

## 2. Target words: text only

Front, Rear, Payoff, Nemesis, Wild, Vulture: **no icons.** Reasons:

1. **The board already shows the target.** A move that picks by a fixed rule lights its slots, and a Wind-up or random move lights the slots it rolled when it is announced (proposal, "On the board: Targets"). The picture of whom it hits is the highlight; the target word only says why those slots, and a player reads that once, in the label ("Nemesis Lance"), in the move's popover and in the glossary.
2. **Six words, six icons would be most of the new set** for something the screen shows already (Misa: show, don't tell, but also less to learn).
3. **The words are the plain part of the label.** Misa's grammar (`grammar.md`, "Boss moves: behaviour and paint") makes the label the thing a player learns once; an icon per target word would add a second vocabulary beside it.
4. **No colour code to invent.** A corner mark per word would have to be a shape (colour is not enough), small enough to sit on the shape icon, and would crowd an 8x8 icon at 1x.

If testing shows players need the target at a glance, the way to add it is one small 3x3 corner mark on the shape icon (six marks, drawn as shapes, never colour alone), not a second glyph beside it. Not proposed now.

## Notes and things that looked suspicious

1. **`reticle` already means two things.** Its comment says "the boss is about to hit this creature", and `modifierIcon` in `dungeon-rooms.ts` also uses it for "extra crits" (`team_crit`). Round 2: combat v2 draws Strike as a crosshair without the circle (`shape-strike`) and gives the plain attack its own sword (`attack`), so the ringed `reticle` is no longer used by combat v2 at all. When the new `crit` icon ships, switch `team_crit` to it.
2. **`shield` is the Guard's role glyph**, so Armour and the Blocked hit cannot use it: a Guard's slot would show a role shield and an armour shield. Hence the new steel breastplate. If Misa prefers one shield, the Guard's role glyph is the one to change.
3. **`sparkle` is the Payoff's role glyph and also "shiny" and "first on server".** It is not touched here, but the "fresh" spark on a mark (Quick Draw) should not use it for a fourth meaning.
4. **Two keyword names differed from their label word:** the keyword Scatter is the label Barrage, and the keyword Leap was the label Leaping Strike (`keywords.json` against `moveLabel`). Leap is settled (decision `2026-11-01-combat-v2-names-a-card-never`: the shape word is Leap), so the Leap icon is `shape-leap`. Scatter against Barrage is still open.
5. **The proposal also asks for an icon per rule card** (19 cards, `cards.json`, shown on the boss card with strength pips and again on creatures whose Knack answers them). That is a separate, larger set of pictures and is **not in this task** (the task is keywords and shapes); it needs its own pass once Misa has seen this one.
6. **Cut order if Misa wants fewer new icons:** the three Store meter heads (name the resource in text), then the silence ward, then the cracked armour, then One-shot.
7. **Two things to remember when these ship.** The plain attack's marker on a target is still "one small marker on its current target" (`proposals/001-combat-v2.md`); it is now the sword, not a crosshair. And the Store box has its content above the rim, so at 1x the content is a few pixels: the count text beside it carries the amount.

## The studio

`pnpm art` gains a `glyph` kind (8x8, flat colour, no outline required, at most 5 colours, more than 8 pixels, a silhouette at least 6 pixels from every shipped glyph and element icon). A glyph set's sheet shows each icon at 6x, 3x and 1x under a heading per group, and, with the set's `shipped` list, the shipped glyphs it reuses on a dim ground beside the new ones, so the whole set is seen together (the catalogue's own sheet shows only the new icons, so a redrawn shipped glyph never makes the library stale).
