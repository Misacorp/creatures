# Scalars registry

Generated by `pnpm scalars` (`packages/sim/src/scalars.ts`). Do not edit by hand: change the value in its source file, run `pnpm scalars` and commit the result. A test fails when this file is stale. The process is in `docs/design/balance-loop.md`.

The knobs are the numbers of `RULES` (`packages/game/src/rules/config.ts`) and the numeric fields of the content data files (`packages/game/src/content/data`). The unit comes from the key name (`...Bp` is basis points, `ms` milliseconds, `...Hours` hours, anything else a count). The meaning is the first sentence of the comment on the field, or on the nearest parent below the system that has one. Sim targets come from the hand-maintained map in `packages/sim/scalar-targets.json` (a path prefix to target ids from `packages/sim/targets.json`; `raid-*` means every target with that prefix). A short array of numbers (up to 8) is one row, a longer one has a row per element.
