## Other friction

- **The full check failed twice on things a quick run would have caught.**
  - 19:59: `collection.test.ts` pins the exact shape of a creature in `/api/state`, and the new `medals` field wasn't in it. The lead had run the games, read budget and query plan tests, but not the whole worker package.

  - Each failure cost a 15-minute rerun.
- **A scripted edit missed silently (18:35).** A Python `str.replace` matched nothing, because Prettier had re-indented the file since it was read, and the result was a syntax error. Several edits in this session used `str.replace` without checking that the old text was found.
- **Leftover refactors from the variations.** The first round wrapped the XP bar and the armchair for one placement option. That stayed in the card after the option was dropped, until the lead's own diff review at 20:05 put the original code back.
