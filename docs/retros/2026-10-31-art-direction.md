## Other friction

- **Parallel art agents all edit `concepts/index.ts` and the generated `docs/art/README.md`,** so nearly every merge conflicted (eight merges). One chained command (`... | tail -1 && git add -A && git commit`) went on after a failing step, because `tail` returned 0, and committed conflict markers. Caught before the push and amended.
- **The lead published the art review page before its review came back.** Prettier had put a space inside the data marker (`/*DATA*/ null`), so the page went live empty for a few minutes. The reviewer found it. Now the marker is a string and the script fails if the data is not written.
- **A bug in the lead's own studio change** (`foe` and `boss` pools used dungeon sprites that were never imported) crashed `pnpm art` for those kinds. Nothing ran the studio on every kind; a drawing agent found it.
- **Drawing agents needed two rounds** on most first drafts (scarves, foes, gear, the glow set), each time for silhouettes that read as other objects (a hammer, a mushroom, a mail slot). The lead's review caught these before Misa saw them, but every round cost 5 to 15 minutes.
- **The stop hook said "unpushed, no remote branch" 8 times** while checks were running. Twice the branch was already pushed: the clone's fetch refspec tracks only a few branches, so the hook cannot see `origin/<branch>`.
- **Rebasing onto `main` after #115's squash merge was denied** (force push). Merging `main` into the branch worked; the PR diff showed only the new work.

## What went well

- The studio loop (0.2 s a render, a coordinate grid, the lint) made drawing rounds fast, and agents used it on their own.
- Choices side by side (pale or dusk Void, three valley directions, three beiges) got quick, clear answers from Misa.
- The art review page gave 17 verdicts in a few minutes from his phone, and they flowed straight into the next round.
- Every code feature got a second-agent review that found real bugs (a stuck blink, the empty page, a fingerprint that ignored the backdrop).
