## Other friction

- **Stop-hook nagging, 20 times.** Subagents edited the shared working tree, so the lead's tree was dirty whenever a turn ended.
- **Parallel agents in one tree.** Shared files (`games-events.json`, `glossary.json`, content and rules index files) broke loading mid-run once, one agent's edit was silently dropped, and the slow sim tests timed out under the combined load.
- **Migration number clash.** Main took migration 38 (#68) while the branch also used 38 and was already on staging. The PR sat conflicted, so CI did not run on two pushes, and this went unnoticed until a deploy check. The fix was an order-independent migration 39.
- **Permission denials.** Restarting the merged branch (reset, force push) was denied three times; the workaround was merging main. `curl` to staging was denied, so the footer was never verified and Misa was asked to check it each time.
- **A flaky test.** A dungeon dev-tool test played on live dice and failed once on CI; it is now seeded.
- **Commentary templates** broke two tests when shortened late; the tests pinned exact wording.

## What went well

- The overnight build landed a playable feature with tested art, engine, server and client, and Misa liked the look straight away.
- The simulator turned "is this fair and fun?" into numbers (bench share, level share, length, quiet stretches) and caught real problems before Misa saw them.
- Each round of feedback was answered with screenshots, and the overflow audit (42 states at 6 widths) made "nothing overflows" checkable.
- Misa's scope freeze was written into the spec and respected.
