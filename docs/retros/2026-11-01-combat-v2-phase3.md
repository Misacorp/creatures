## Other friction

- **Three agents' `pnpm check:changed` runs were killed by their own tool time limit** (about 580 s; the run takes about 11 minutes), and they finished the checks package by package. The restart of the container also cut one of the lead's runs.
- **The parity digest moved with every rename.** Case labels and fight log texts held names, so each name batch needed a proof (replay with the old names) and a `--write`. Labels became answer numbers after batch 1; the log texts still carry names.
- **The decisions index went stale once.** The lead edited `combat.md` with a script, which skips the hook that runs `pnpm decisions fix`; an agent later found `pnpm decisions check` failing.
- **Rule changes broke three lab tests first** (Mired fading every round weakened two Storm Sovereign answers; the Puddle Imp's dodge question stopped working as a Scatter). The agent stopped, as briefed, and a second round tuned them; the Puddle Imp's question had to change to a Guard.
- **Worktrees stayed locked** after their agents finished (four times), and one agent left an entry in the shared git stash (its own drop was refused); the lead unlocked, checked and cleaned by hand.
- The stop hook asked to push three times while checks ran; rightly ignored.
- Lab test time is about 20 s on this machine, double the 10 s budget in the roadmap; nobody acted on it.

## What went well

- **The parity digest made the big moves safe:** 1,299 fights held through five slices of code moving between packages, and every deliberate change was proven or measured.
- **The names pages** (a page per batch saving Misa's answers to a store the lead reads back) turned 200+ names into five quick sittings, with round 2 pages for the notes.
- **Overnight work** carried on safely: agents stopped on red tests instead of loosening thresholds, and the morning summary named the open choices.
- **Misa's move model is recorded where design starts** (`grammar.md`, "Boss moves: behaviour and paint"), and the content test enforces it.
